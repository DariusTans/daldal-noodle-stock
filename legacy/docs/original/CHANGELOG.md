# v0.8.0 — 31 ตุลาคม 2026

คง localStorage key และ schema 6 รวมทั้งกฎยอด/อนุมัติเดิม ทดสอบ baseline ก่อนปรับและเส้นทาง UI หลังปรับ พร้อมคู่มือและบท UAT แยกผลอัตโนมัติจากทีมร้าน ใช้ Product และ Site เดิม

# ประวัติอัปเดต

## v0.4.0 — 15 ตุลาคม 2026

รอบ 4: ต่อรายการเสนอซื้อที่ตรวจแล้วเป็นใบจัดซื้อ เทียบแหล่งซื้อ/บรรจุ/ค่าส่ง/ค่าเพิ่ม/ส่วนลด พร้อมราคาและเวลาอ้างอิง คนเลือก ตั้งเกณฑ์ทดลอง ส่งพิจารณา อนุมัติ/ส่งกลับ/ไม่อนุมัติ และบันทึกซื้อแล้วรอตรวจรับ

ข้อมูล schema 4 พร้อมสำรองก่อน migration จาก 1–3 เก็บข้อมูลเดิม บังคับพิจารณาใหม่เมื่อรายละเอียดหรือเกณฑ์เปลี่ยน ตรวจยอดต้นทาง stale กันใบซ้ำ ไม่เพิ่มสต็อกก่อนตรวจรับ ยังคง Site และ URL เดิม

ผ่าน logic/UI tests ของจัดซื้อพร้อม regression รอบ 1–3 รองรับมือถือ เอกสารและไฟล์ส่งมอบอัปเดตใน Product เดิม


## v0.3.0 — 14 ตุลาคม 2026

รอบ 3: รับเข้า เบิกใช้ ของเสีย ปรับเพิ่ม/ลด กลับรายการพร้อมเหตุผล ตรวจความครบก่อนใช้ยอดคำนวณ ตั้งจุดเตือนและยอดเป้าหมาย ร่างเสนอซื้อพร้อมตรวจจำนวนและป้องกันรายการซ้ำ/ล้าสมัย

เพิ่ม schema 3 พร้อม migration/สำรองจาก 1 และ 2 รักษารอบนับและรหัสเดิม รอบนับใหม่ใช้ยอดคาดหมายเมื่อข้อมูลตรวจครบ และเริ่มฐานใหม่โดยไม่บวกรายการเก่าซ้ำ รองรับมือถือ ใช้ Site และลิงก์เดิม

ผ่านกฎข้อมูลและ browser workflow รอบ 3 พร้อม regression รอบ 1–2 ยังเป็น browser-local prototype และบทบาทจำลอง รายการตรวจแล้วรอจัดซื้อยังไม่ใช่การซื้อหรืออนุมัติเงิน


## v0.2.0 — 13 ตุลาคม 2026

รอบ 2: เพิ่มนับสต็อก ร่าง ส่งตรวจ ส่งกลับพร้อมเหตุผล ตรวจยืนยัน ล็อกประวัติ และยอดนับล่าสุด เปรียบเทียบรอบที่ยืนยันก่อน รักษาข้อมูลเดิมผ่าน migration พร้อมสำรอง ตรวจป้องกันการเขียนทับจากแท็บอื่น และแสดงการ์ดสำหรับนับบนมือถือ

ผ่านทดสอบ logic และ browser ทั้งระบบเดิมและรอบ 2 ไม่มีข้อมูลทดสอบรวมในไฟล์เผยแพร่ ใช้ Site และลิงก์เดิม
